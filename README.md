# 🏨 ANSH Hotel Management System

<div align="center">
  
### A Modern Full Stack MERN Hotel Management Platform

Built using **MongoDB, Express.js, React.js, Node.js, Cloudinary & JWT Authentication**.

A modern Hotel Management System built with the **MERN Stack** to manage hotel rooms, users, bookings, and administration through a responsive web interface.

[![GitHub](https://img.shields.io/badge/GitHub-Repository-black?style=for-the-badge&logo=github)](https://github.com/Muhammad-Ali232/ansh-hotel-management-system)

</div>

---

# 📌 About the Project

ANSH Hotel Management System is a complete hotel management solution developed using **MongoDB, Express.js, React.js, and Node.js**.

It provides secure authentication, room management, booking features, profile management, and an admin dashboard.

# ⚙️ Installation

## Clone Repository

```bash
git clone https://github.com/Muhammad-Ali232/ansh-hotel-management-system.git
```

## Backend

```bash
cd ansh-hotel-management-system
npm install
node server.mjs
```

## Frontend

```bash
cd User
npm install
npm run dev
```

Frontend runs at:

```text
http://localhost:5137
```
